# TripCo V4 Visual Identity

## الفكرة
هوية تجمع أربع بيئات سعودية داخل علامة واحدة: **الأخضر السعودي، البحر الأحمر، الرمال والتراث**. رمز الشعار مبني على دبوس موقع يلتقي بداخله خط موجة/كثيب وشمس، ليعبر عن رحلة متعددة البيئات داخل المملكة.

## الألوان الأساسية
- Deep Forest: `#071F1A`
- Saudi Green: `#0B6F55`
- Red Sea Teal: `#0C8A91`
- Sand: `#E9D5B3`
- Heritage Gold: `#C89045`
- Coral Accent: `#D66E52`
- Cloud: `#F7F5F0`

## مبادئ الواجهة
- مساحات كبيرة وواضحة، وحواف مستديرة حديثة.
- صور الوجهات هي العنصر البصري الرئيسي، مع زخرفة سعودية خفيفة جدًا.
- الأخضر للهوية والإجراءات الرئيسية، والتركواز للبحر والميزات التقنية، والذهبي للتراث والمواسم.
- لا تستخدم الزخارف بكثافة؛ تستخدم كطبقة خلفية منخفضة التباين.
- التصميم ثنائي اللغة، ويجب أن يعمل بنفس الجودة في RTL وLTR.

## نبرة المنتج
TripCo لا يظهر كدليل أماكن فقط؛ الواجهة تقدمه كـ **Saudi Journey OS**: اكتشاف، تخطيط، تنظيم، تجربة أثناء الرحلة، ومحفظة موحدة.


## Booking UI extension
The booking layer keeps the same Saudi-green / Red-Sea / sand identity while using brighter white inventory cards, compact form fields and high-contrast transaction states. World Cup 2034 uses a darker event treatment with gold accents and clear non-official ticket labels.
