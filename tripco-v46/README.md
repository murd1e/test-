# TripCo v4.6 — Saudi Journey OS

TripCo v4.6 expands the tourism prototype into a connected journey platform with booking-oriented flows.

## New in v4.6
- Hotel discovery and booking prototype with city/date/guest filters, price filters and stay comparison.
- Flight search prototype with route, date, traveler count, direct-flight filter and trip-cart integration.
- Unified trip cart now supports stays, flights, experiences and World Cup 2034 demo ticket categories.
- Booking review / demo confirmation flow with local trip references saved to Trip Wallet.
- Rebuilt World Cup 2034 hub with ticket center, travel and stay, fan services, match-day flow, accessibility, support and digital services.
- 33 World Cup service modules covering match, travel, fan experience, digital features and visitor support.
- Expanded global navigation and command search.
- PWA cache updated for the new booking pages.

## Important prototype limitations
- Hotel inventory, flight schedules, prices and booking references are illustrative local demo data.
- The current build does not process real payments or create real reservations.
- World Cup 2034 ticket cards are UI prototypes only and are not official FIFA tickets or official pricing.
- The production version would require authorized booking APIs, payment gateway, backend/database, live availability and official event data sources.

## Run locally
Windows: run `start-tripco.bat`

macOS/Linux:
```bash
./start-tripco.sh
```

Then open the localhost address shown by the server. Running through localhost is also recommended for camera/AR permissions.
